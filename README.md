# Soil Health Analyzer Using Python

## Project Overview
A beginner-level agricultural data analysis project
that analyzes soil pH, electrical conductivity (EC),
and organic carbon using Python.

## Objectives
- Analyze soil test data.
- Calculate average soil parameters.
- Compare soil samples using graphs.
- Import and export CSV files.
- Create an interactive soil analysis interface.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- Matplotlib
- IPyWidgets

## Features
- Soil parameter input and interpretation.
- Multiple soil sample analysis.
- CSV import and export.
- Summary statistics.
- Graphical visualization.
- Interactive analysis interface.

## Limitations
The current dataset uses illustrative sample values.
Interpretations require validation against appropriate
laboratory methods and soil testing standards.

## Future Improvements
- Add more soil parameters.
- Use real laboratory datasets.
- Improve the dashboard.
- Generate formatted soil reports.
